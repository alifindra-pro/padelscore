# Audit bug — 13 Oktober 2026

## Perbaikan

- Portal turnamen dan scoreboard tidak lagi terjebak loading ketika API gagal: tampil pesan kesalahan, tombol coba lagi, dan tautan kembali.
- Direktori/peringkat pemain menampilkan kegagalan pemuatan dan menyediakan percobaan ulang.
- Peringkat menghitung seluruh pemain dalam organisasi sebelum mengambil hasil teratas; batas 100 pemain sebelumnya dapat menghilangkan pemain yang layak masuk peringkat. Urutan seri dibuat deterministik.
- Gelar single elimination hanya dihitung pada babak terakhir tanpa tujuan pemenang berikutnya; kemenangan semifinal tidak lagi dihitung sebagai gelar.
- Scoreboard menerima snapshot SSE saat koneksi awal/ulang. Portal turnamen memuat ulang kondisi lapangan saat koneksi terbentuk. Callback hook SSE menggunakan state React terbaru.
- Penulisan SSE menangani Promise rejection saat klien terputus; kegagalan heartbeat membersihkan langganan dan timer.

## Bukti verifikasi

- **104/104 tes unit/integrasi lulus** dengan PostgreSQL lokal, termasuk regresi peringkat dengan lebih dari 100 pemain dan kemenangan semifinal.
- TypeScript dan build produksi alternatif `npx next build --webpack` lulus.
- `tests/browser/tournament-flow.cjs`: pembuatan acara, kategori, lapangan, pasangan, drawing, jadwal, empat langkah pada tiga lebar layar, serta antrean skor offline dan sinkronisasi kembali lulus.
- `tests/browser/responsive.cjs`: tujuh halaman pada lebar 390/768/1440px (21 kombinasi), tidak ada pageerror atau overflow halaman.
- `tests/browser/error-recovery.mjs`: kegagalan API lalu percobaan ulang berhasil pada turnamen, scoreboard, dan pemain; snapshot skor SSE diterapkan. Data API disimulasikan khusus untuk menguji kondisi kegagalan secara deterministik.
- `git diff --check` lulus.

## Batas dan temuan tersisa

- Lint seluruh repositori **belum bersih: 123 error, 29 warning**, terutama tipe `any`, aturan hooks React, impor CommonJS, dan variabel tidak terpakai. Aturan lint tidak dinonaktifkan untuk menyembunyikan temuan.
- Build standar Turbopack terhambat worker CSS dengan `binding to a port: Operation not permitted`, termasuk percobaan di luar sandbox. Build alternatif webpack digunakan untuk memeriksa kompilasi produksi; ini tidak membuktikan pipeline CSS Turbopack berhasil.
- PostgreSQL lokal aktif. Kegagalan koneksi dari percobaan sandbox bukan bukti server database mati; tes berhasil ketika diberi akses lokal yang sesuai.
- Redis, penyimpanan S3/MinIO, dan perangkat mobile native tidak diuji dalam audit ini.

Audit ini tidak menyatakan aplikasi bebas seluruh bug atau siap rilis tanpa temuan tersisa.
